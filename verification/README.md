# Verification scope

- `live-results.json`: actual HTTP comparisons with the live Fruityvice array and
  verification of every corresponding MongoDB log, including result count, route,
  method, client IP and UTC date.
- `postman-results.json`: the full Postman collection execution report generated by
  Newman. Its `run.stats` and `run.failures` fields contain the outcome.
- `unit-tests.txt`: captured deterministic test output.
- `database-restore.json`: result of restoring the native dump into an isolated
  verification database and comparing the restored documents with the JSON export.

The Postman collection was executed using Newman, the official Postman collection
runner. The desktop application was opened, but desktop capture timed out, preventing
verification through its graphical interface. Import the supplied collection into
Postman and choose Run to reproduce the same requests and assertions there.

The course website upload is a manual submission step. GitHub publication does not
replace the required ZIP submission to the course website.
